# 사람 브라우저 — Android Alpha

웹페이지를 읽는 자리에서 질문·댓글·평가·판단을 남기는 로컬 브라우저입니다.
웹사이트는 휴대폰의 Android System WebView에서 직접 열립니다. 원격 브라우징 서버는 사용하지 않습니다.

## 설치

[Android APK 다운로드](https://github.com/wilcoco/human-browser/releases/download/v0.1.0-alpha/human-browser-android-0.1.0-alpha.apk)

1. Android 8.0 이상 기기에서 APK를 내려받습니다.
2. Android가 요청하면 다운로드에 사용한 앱의 ‘이 출처 허용’을 설정합니다. 조직·기기 정책에 따라 설치가 제한될 수 있습니다.
3. 설치 후 사람 브라우저를 엽니다. 처음에는 외부 요청 없이 동작하는 합성 예제가 표시됩니다.
4. 아래의 **페이지 기록** 또는 본문을 길게 선택한 뒤 **선택 인용**을 누릅니다.
5. **내용 확인 → 확인하고 저장**을 선택해야 승인한 기록이 됩니다.

업데이트할 때는 같은 서명으로 배포된 새 APK를 기존 앱 위에 설치합니다. 앱을 삭제하면 로컬 기록과 키도 삭제됩니다. 아직 자동 업데이트는 없습니다.

## 포함 기능

- HTTPS 웹 탐색과 검색, 뒤로가기, 새로고침
- 페이지 주소에 따라 바뀌는 기록 목록과 전체 로컬 기록 보기
- 출처·선택 문장이 고정된 초안과 자동 보관
- 댓글·질문·답변·평가·기록 연결
- 결정·보류·불일치 보존·중단, 이유 없는 보류 허용
- 읽기 전용 확인 화면을 거친 로컬 저장과 서명된 철회 이력
- 다른 앱에서 HTTPS 링크를 공유받아 열기
- 서명된 기록 JSON 내보내기

## 데이터와 한계

기록과 초안은 앱 내부에 저장하며 앱이 댓글 서버나 AI로 전송하지 않습니다. 방문한 웹사이트와 검색 서비스에는 일반적인 웹 요청이 전달됩니다. 웹사이트 쿠키·저장소는 기기에 남을 수 있습니다. Android System WebView를 최신 상태로 유지하세요.

AndroidKeyStore의 P-256 키로 기록을 서명합니다. 이는 키의 행위를 확인하며, 고유한 인간이나 내용의 진실을 증명하지 않습니다. Android 실험 형식 `android-local-alpha/1`이며 Mac 개발판의 기록 형식과 호환되지 않습니다.

현재 다른 사람의 댓글 동기화, AI 관계 제안, 분산망, 다중 탭, 파일 업로드·다운로드, 웹 카메라·마이크·위치 권한, 기록 가져오기·키 복구는 제공하지 않습니다. JSON 내보내기는 검증 가능한 기록 사본이며 현재 앱으로 복원하는 기능은 없습니다. 새 창을 요구하는 링크와 일부 로그인·결제 사이트는 작동하지 않을 수 있습니다. 일반 브라우저를 완전히 대체하는 정식 제품이 아닌 기능 검증용 알파입니다.

## 빌드

저장소 루트에서 `bash scripts/build-android.sh`를 실행합니다.

필요 도구: JDK 17, Android SDK Platform 35, Build Tools 34.0.0, Python 3, zip, OpenSSL.
`ANDROID_SDK_ROOT`로 SDK 경로를 지정할 수 있습니다. 외부 앱 라이브러리와 원격 빌드 서버가 필요하지 않습니다. APK는 `outputs/`에 만들어집니다.

처음 빌드하면 `.release-keys/android/`에 배포용 키와 암호 파일이 만들어집니다. 이 폴더는 Git에 포함하지 않습니다. 업데이트를 위해 안전하게 보관해야 하며, 기존 키를 잃었을 때 스크립트가 임의로 새 키를 생성하지 않습니다. 직접 빌드한 APK는 공식 배포 APK와 서명이 달라 덮어 설치되지 않습니다.

## 시험

- `bash scripts/test-android-records.sh`: 독립 테스트 패키지의 저장·서명·철회 검사 APK 생성
- `bash scripts/test-android-browser.sh`: 브라우저 승인 흐름 검사 APK 생성
- 테스트는 개인 데이터가 없는 전용 에뮬레이터에서 실행합니다. 테스트 APK는 배포용 앱에 포함되지 않습니다.
- 공개 배포 파일은 `apksigner verify`와 첨부 SHA-256 파일로 무결성을 확인할 수 있습니다.
