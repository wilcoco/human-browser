# 사람 브라우저 macOS 0.2.0 Alpha

**[Mac 공용 ZIP 다운로드](https://github.com/wilcoco/human-browser/releases/download/macos-v0.2.0-alpha/human-browser-macos-0.2.0-alpha-universal.zip)**

macOS 14 이상, Apple Silicon·Intel 공용입니다. Railway의 공개 댓글·질문·평가·판단을 Android 0.2.x와 함께 읽고 작성합니다. 웹페이지는 맥에서 직접 열립니다.

## 설치와 업데이트

1. 기존 사람 브라우저를 종료하고 ZIP을 풉니다.
2. `Human Browser.app`을 응용 프로그램 폴더에 넣습니다. 기존 앱이 있으면 교체합니다. Application Support의 데이터 폴더는 삭제하지 마세요.
3. 주소창에서 페이지를 열고 오른쪽 **함께 보는 판단 → 공유 연결**을 켭니다.
4. **페이지에 의견 남기기 → 내용 확인 후 저장 → 확인하고 공개**를 누르면 같은 URL을 보는 사람에게 공개됩니다. 개인 보관은 **이 기기에만 저장**을 선택합니다.
5. 기존 개인 기록은 카드의 **이 기록 공개하기**를 눌러 내용과 출처를 확인하고 공개합니다. 다른 사람의 기록은 자신의 기록으로 재공개할 수 없습니다.

이 배포는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 받지 않았습니다. 개발자 확인 경고가 뜰 수 있습니다. 출처를 확인한 후 사용자가 직접 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 선택할 수 있습니다. [Apple 공식 안내](https://support.apple.com/ko-kr/102445).

## 공유와 동기화

- 공유 연결 중에는 현재 페이지의 정확한 URL을 Railway에 보내 공개 판단을 조회합니다. 페이지·탭 이동 시 연동하고, 열린 앱에서 30초마다 갱신합니다. **새로고침·재시도**도 제공합니다.
- 공유 연결은 처음에는 꺼져 있습니다. 연결을 켜거나 직접 공개를 승인하면 활성화됩니다. 끄면 이후 조회·재전송을 중지합니다. 이미 진행 중인 요청은 서버에 도착했을 수 있습니다.
- URL·제목·인용·본문·평가·대상 ID·시간·기기 공개키와 서명은 직접 공개를 승인한 경우에만 게시됩니다. 초안과 기존 개인 기록은 자동 업로드하지 않습니다.
- 공개 카드에서 답변·평가·의미 연결을 작성할 수 있습니다. 대상 기록의 정확한 ID를 유지합니다. 비공개 대상에 연결한 기록은 대상을 먼저 직접 공개해야 게시할 수 있습니다.
- 승인한 게시·철회 요청은 먼저 기기에 저장합니다. 오프라인·응답 유실·앱 재시작 후에도 같은 ID와 서명으로 재시도하므로 중복 게시하지 않습니다. 앱을 열고 공유 연결을 켜 두어야 재시도합니다.
- **공개 철회**는 서버 반영 후 목록에서 숨깁니다. 서버 확인 전에는 다른 기기에 보일 수 있습니다. 다른 사람의 답변·평가, 철회 이력 및 이미 복사된 내용은 남습니다.
- 목록은 한 번에 최대 25건이며 **이전 공개 기록 더 보기**를 제공합니다. 주기 갱신 시 최신 페이지로 돌아갑니다.
- `www`·모바일 하위 도메인·쿼리·해시가 다르면 별도 URL입니다. 비교하려면 두 기기에서 같은 주소를 열어야 합니다. Android에서는 **공개 보기**로 조회하고 필요하면 새로고침하세요.

이 동기화는 **공개 판단의 공동 조회·게시**입니다. 로그인 기반 개인 초안·서명 키 동기화는 아직 없습니다. 맥과 Android는 서로 다른 기기 키로 작성하며 다른 기기의 기록을 대신 철회할 수 없습니다. 서명은 키의 작성 사실을 검증하며 고유한 인간이나 의견의 진실을 인증하지 않습니다.

## 데이터와 호환성

- 개인 기록과 초안은 `~/Library/Application Support/org.humanbrowser.alpha/`에 유지됩니다. 0.1.0의 로컬 기록 형식과 키는 변경하지 않습니다.
- 공개 승인 기록·전송 상태·로컬 ID 대응은 같은 디렉터리의 `shared-records-v1.json`에 원자적으로 저장합니다. 공개 P-256 서명 키는 별도의 macOS 키체인 항목에 저장합니다. 키가 없거나 맞지 않으면 새 신원으로 자동 교체하지 않습니다.
- 공개 기록은 기존 Android/Railway `android-local-alpha/1` 형식과 호환됩니다. Mac의 기존 개인 JSON 내보내기·가져오기는 개인 기록 전용이며 공개 저장소·키 백업 기능이 아닙니다.
- 웹 쿠키와 세션은 앱 종료 시 초기화됩니다. 판단 기록은 유지됩니다. 공유 API는 웹 쿠키를 사용하지 않고 리디렉션을 따르지 않습니다.
- 배포 파일에는 사용자 기록, 서명 개인키, 개발 PC 데이터 경로가 포함되지 않습니다.
- 초기 개발판의 `work/runtime`은 자동으로 옮기지 않습니다. 필요하면 기존 앱에서 개인 기록을 내보내 가져오세요.

외부 앱 전용 링크, 일부 팝업·로그인·결제, 웹 파일 다운로드·업로드 및 카메라·마이크 권한은 지원하지 않습니다. AI·분산망은 후순위입니다.

## 빌드와 검증

Xcode Command Line Tools, macOS SDK, Python 3가 필요합니다. 공유 상호운용 검사에는 Node.js도 필요합니다.

```sh
bash scripts/build-macos.sh
bash scripts/test-macos-sharing.sh
```

Universal 앱은 `outputs/macos-0.2.0/Human Browser.app`, ZIP과 SHA-256 파일은 `outputs/`에 생성됩니다. 이전 실행 앱을 덮어쓰지 않도록 별도 출력 폴더를 사용합니다.

`bash scripts/test-macos-sharing-live.sh`는 선택적 운영 API 검사입니다. 고유한 `.invalid` URL에 합성 기록을 게시한 뒤 모두 철회합니다. 사용자 데이터·키를 사용하지 않습니다. [검증 결과](VALIDATION.md).
