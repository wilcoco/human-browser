# macOS 0.1.0 Alpha 배포 검증

2026-10-23, macOS Apple Silicon 로컬 환경에서 확인했습니다.

- arm64·x86_64 각각 컴파일 및 Universal 실행 파일 병합 성공. 최소 OS 타깃 macOS 14.
- 배포 앱의 ad-hoc 서명 검증 통과. Apple Developer ID 서명·공증은 미완료.
- 배포 앱 실행, 저장소 오류 없는 초기 화면과 실제 네이버 기사 렌더링 관찰.
- 사용자별 Application Support 디렉터리 생성 확인. 개발용 절대 데이터 경로 제거.
- ZIP 구성 검사: 실행 파일, Info.plist, 코드 서명, 합성 연습 HTML만 포함. 사용자 기록·서명 개인키 없음.
- 새 빌드에 연결한 core standalone 검사 12개 시나리오 통과, 실패 0. 출처 고정, 명시적 승인, 변조·키 대체 거절, 중복 가져오기, 철회 순서·타인 철회, 재시작 저장, 원자적 가져오기, 스키마 검사, 보류, 정확한 대상 연결, 키 오류 시 신원 유지, Ed25519 벡터 포함.
- Intel 빌드는 생성·서명을 검사했으며 Intel 실기기 실행은 확인하지 않았습니다.
- 웹 세션은 일시적이며 개인 판단은 로컬 저장합니다. Railway 공유·Android 동기화는 이 맥판의 기능이 아닙니다.

검사는 합성 데이터와 임시 저장소를 사용했으며 사용자 의견을 자동 생성하거나 외부에 게시하지 않았습니다.
