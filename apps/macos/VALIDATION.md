# macOS 0.2.0 Alpha 공유 검증

2026-10-23, macOS Apple Silicon 환경.

- 공유 검사 25개 통과: P-256·고정 JSON 서명, 본문 변조·키 대체 거절, Android 실제 내보내기 fixture 검증, 공개 전 무전송, 중복 게시 방지, 오프라인·재시작·응답 유실 재전송, 정확한 URL 분리, 평가 대상 유지, 비공개 대상 자동 게시 방지, 철회 소유권·순서·중복, 오류 응답 원자적 거절, 이전 URL의 늦은 응답 격리.
- 맥 생성 서명 기록을 변경하지 않은 Node Railway 검증기로 검증. 한글·슬래시·따옴표·줄바꿈·이모지 포함.
- 운영 Railway API에서 두 개의 독립된 임시 클라이언트로 게시→상대 조회→상대 평가→역방향 조회→원본 철회→평가 보존→전체 검사 기록 철회 완료. 고유한 합성 URL 사용, 사용자 판단·키 사용 없음. 공개 목록이 비었음을 확인.
- 실제 SwiftUI 화면에서 공개 목록·동기화 시각·공개 평가 작성·사람의 확인 화면·공개 완료·철회를 확인. UI 검사는 별도 앱 ID와 임시 저장소 및 메모리 API로 수행하여 사용자 앱과 운영 의견을 변경하지 않음.
- 기존 개인 기록 core 검사 12개 통과. 기존 로컬 Ed25519 프로토콜은 그대로 유지.
- arm64·x86_64 Universal 빌드 및 ad-hoc 서명 검증. Intel 실기기 실행은 미확인. Apple Developer ID 서명·공증은 미완료.
- 공개 프로토콜의 Android 상호운용을 fixture/서버 검증으로 확인했으며 이번 macOS 변경에서 Android 실기기 UI를 새로 조작하지 않음.

전송 실패 시 요청은 기기에 남으며 앱 실행·공유 연결 상태에서 재시도합니다. 서버 장애, 계정별 비공개 동기화, 기기 간 동일 신원·철회 권한 이전은 이 검증의 보장 범위가 아닙니다.
